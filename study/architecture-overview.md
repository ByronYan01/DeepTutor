# DeepTutor 整体架构概览

## 概述

DeepTutor 是一个 **AI 驱动的个性化学习助手**，采用前后端分离的全栈架构，通过多 Agent 协作提供智能教育服务。

## 2. 核心功能模块

### 2.1 模块概览

| 模块 | 功能 | 关键特性 |
|------|------|----------|
| **Solver** | 问题求解 | 双循环架构, WebSocket 流式输出 |
| **Research** | 深度研究 | 三阶段流水线, 动态主题队列 |
| **Guide** | 引导学习 | 交互式页面生成, 个性化问答 |
| **Question** | 题目生成 | 自定义模式, 仿真模式 |
| **IdeaGen** | 创意生成 | 双过滤工作流 |
| **CoWriter** | 协作写作 | AI 辅助编辑, TTS 生成 |
| **Knowledge** | 知识库 | 文档上传, RAG 索引 |

## 总结

DeepTutor 采用 **四层架构** 设计:

1. **UI 层** - Next.js 前端，提供交互界面
2. **API 层** - FastAPI 网关，统一接口管理
3. **Agent 层** - 多 Agent 协作，智能任务处理
4. **服务层** - 抽象底层能力，支持多提供商

核心优势:
- **模块化设计** - 功能模块独立，易于扩展
- **多 Agent 协作** - 复杂任务分解，专业化处理
- **服务抽象** - 底层服务可替换，灵活适配
- **容器化部署** - 一键启动，环境一致
