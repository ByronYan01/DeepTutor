# DeepTutor 功能演示指南

本指南提供详细的测试操作步骤，帮助您展示 DeepTutor 的核心功能亮点。

## 📋 准备工作

### 环境配置

1. **配置 API 密钥** - 编辑 `.env` 文件:

   ```bash
   # 必需配置
   LLM_BINDING=openai
   LLM_MODEL=gpt-4o
   LLM_API_KEY=sk-your-key
   LLM_HOST=https://api.openai.com/v1

   EMBEDDING_BINDING=openai
   EMBEDDING_MODEL=text-embedding-3-small
   EMBEDDING_API_KEY=sk-your-key
   EMBEDDING_HOST=https://api.openai.com/v1
   EMBEDDING_DIMENSION=1536
   ```

2. **启动服务**:

   ```bash
   docker compose up
   ```

3. **访问前端**: http://localhost:3782

## 🎯 演示流程 (推荐 15 分钟)

### 第一步: 知识库管理 (2 分钟)

**目标**: 展示文档上传和智能解析能力

1. 点击侧边栏 **"Knowledge"** 进入知识库页面
2. 点击 **"Create Knowledge Base"** 创建新知识库
3. 输入名称 (如: "Python Tutorial")
4. 上传准备好的 PDF 文档
5. **等待解析完成** - 观察进度条

**亮点展示**:

- ✅ 支持 PDF/TXT/Markdown 多格式
- ✅ 自动文本提取和分块
- ✅ 向量化索引进度可视化

---

### 第二步: 问题求解 Solver ⭐ (5 分钟)

**目标**: 展示核心 AI 推理能力和 Agent 协作过程

1. 点击侧边栏 **"Solver"** 或首页
2. 在顶部选择刚创建的知识库
3. 输入问题 (选择以下任一问题，或自行发挥)
4. 点击 **发送**，观察推理过程

**推荐测试问题** (针对 Transformer 论文):

| 类型         | 具体问题                                                             | 预期效果                 |
| ------------ | -------------------------------------------------------------------- | ------------------------ |
| **概念解释** | FastAPI 的依赖注入 (Dependency Injection) 是什么？请给我一个具体例子 | 展示 RAG 检索 + 代码理解 |
| **对比分析** | FastAPI 和 Flask 有什么区别？各自的优势是什么？                      | 展示多步推理能力         |
| **实践应用** | 如何用 FastAPI 实现一个简单的 RESTful API？请给出完整代码            | 展示代码生成能力         |
| **深入理解** | FastAPI 的 async/await 是如何工作的？与同步代码有什么区别？          | 展示深度理解能力         |
| **最佳实践** | 根据文档，FastAPI 项目的目录结构应该怎么组织？                       | 展示全文理解能力         |

**推荐测试问题** (针对 Docker 文档):

| 类型         | 具体问题                                                                   | 预期效果         |
| ------------ | -------------------------------------------------------------------------- | ---------------- |
| **概念解释** | Docker 容器和虚拟机有什么区别？为什么容器更轻量？                          | 展示核心概念理解 |
| **实践应用** | 如何写一个 Dockerfile 来容器化一个 Python Web 应用？                       | 展示代码生成能力 |

## 🌟 核心技术亮点总结

### 1. 多 Agent 协作架构

```
用户提问 → API 网关 → Agent 协作 → 工具调用 → 结构化输出
                          ↓
              ┌─────────────────────────┐
              │ InvestigateAgent (分析) │
              │ ManagerAgent (规划)     │
              │ SolveAgent (推理)       │
              │ ResponseAgent (输出)    │
              └─────────────────────────┘
```

### 2. 双循环推理 (Solver)

| 循环          | 功能               | Agent                      |
| ------------- | ------------------ | -------------------------- |
| Analysis Loop | 信息收集与工具调用 | Investigate → Note         |
| Solve Loop    | 逐步推理与答案生成 | Manager → Solve → Response |

### 3. 三阶段研究 (Research)

```
Planning → Researching → Reporting
(主题优化)   (动态队列)    (报告生成)
```

### 4. 多服务提供商支持

| 类型      | 支持的提供商                                  |
| --------- | --------------------------------------------- |
| LLM       | OpenAI, Azure, Anthropic, DeepSeek, Ollama... |
| Embedding | OpenAI, Jina, Cohere, HuggingFace...          |
| RAG       | LightRAG, Naive, Hybrid                       |
| Search    | Perplexity, Tavily, Serper, Jina...           |

| -------------- | -------------------------------- |
