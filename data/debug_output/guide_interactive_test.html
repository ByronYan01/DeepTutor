监督学习与无监督学习

监督学习

监督学习是一种机器学习方法，通过使用带标签的训练数据来学习输入到输出的映射关系。常见的监督学习算法包括线性回归、逻辑回归、决策树、支持向量机和神经网络。

标签的作用：

  • 指导模型学习正确的映射关系。
  • 评估模型性能。
无监督学习

无监督学习则使用没有标签的数据，模型需要自己发现数据中的模式和结构。常见算法包括 K-Means 聚类、层次聚类、PCA 降维和自编码器。

如何评估模型好坏：

  • 内部一致性：模型内部的簇是否紧密。
  • 外部一致性：如果有一些已知的类别标签，模型能否正确地识别这些类别。
  • 预测能力：模型能否准确预测新的未见过的数据。

监督学习的核心特点：

  • 有明确的「正确答案」用于指导学习。
  • 常用的评估指标包括准确率、精确率、召回率等。

无监督学习的核心特点：

  • 没有明确的「正确答案」，需要自主发现数据中的隐藏结构。
  • 常用的评估指标包括轮廓系数、Silhouette Score等。
监督学习与无监督学习的区别
有标签
无标签
监督学习需要标签来指导学习，而无监督学习则需要自主发现数据结构。

          def linear_regression(X, y):
            # 计算权重
            w = np.linalg.inv(X.T @ X) @ X.T @ y
            return w
💡 提示
在监督学习中，标签是必不可少的，因为它们提供了学习的目标。而在无监督学习中，模型需要自己找到数据中的结构，因此标签不是必需的。
⚠️ 注意
无监督学习的评估通常更加复杂，因为它缺乏明确的标签来进行直接比较。因此，需要更多的内部和外部一致性指标。
